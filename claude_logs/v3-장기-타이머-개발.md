## 결정

### LaunchedEffect(Unit) 채택
LaunchedEffect(activePlayer) 대신 LaunchedEffect(Unit) 단일 루프 사용.
race condition 우려: delay 완료 시점과 LaunchedEffect 재시작 시점 사이에 틱이 잘못된 플레이어를 차감할 수 있음.
단일 루프에서 매 tick마다 `val active = activePlayer`로 현재값 읽어 처리.

### 전체 영역 탭으로 착수
체스 시계 앱 UX 채택 — 플레이어 영역 전체를 탭하면 착수.
Surface에 clickable(enabled = isActive && gameStarted && !isGameOver) 적용.

### P2 영역 180도 회전
PlayerHalf에 Modifier.rotate(180f) 적용.
rotate()는 draw transform이므로 weight(1f)와 레이아웃 충돌 없음.

### AutoFitText 재사용
HomeScreen.kt의 internal AutoFitText를 TwoPlayerTimerScreen/ResultScreen에서 재사용.
같은 모듈(app) 내에서 internal 접근 가능 → 별도 파일로 이동 불필요.
