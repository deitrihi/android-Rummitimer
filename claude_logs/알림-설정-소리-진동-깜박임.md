# 알림 설정 (소리·진동·화면 깜박임)

## 날짜
2026-06-30

## 요청
타이머 종료 시 사용할 알림 방법을 설정 메뉴에서 토글로 선택할 수 있게 구현.
- 소리: 현재 비프음 사용
- 진동: 중간 세기 (500ms)
- 깜박임: 앱 테두리 빨간색 3회 깜박임

## 행동

### 신규 파일
- `AlertHelper.kt` — 소리/진동/깜박임 설정을 SharedPreferences(`rummitimer_settings`)에 저장하고 `triggerAlerts()` 메서드로 활성화된 알림 실행
  - 기본값: 소리 true, 진동 false, 깜박임 false
  - Android API 31+ (S): `VibratorManager`, 이전 버전은 deprecated `Vibrator` 사용

### 수정 파일
- `AndroidManifest.xml` — VIBRATE 권한 추가
- `SettingsScreen.kt` — 알림 섹션 추가 (3개 파라미터: alertSound/alertVibration/alertFlash)
- `MainActivity.kt` — RummitimerApp에 6개 파라미터(값+콜백) 추가, AlertHelper로 초기값 로드
- `GeneralTimerScreen.kt` — 타이머 완료 시 AlertHelper.triggerAlerts 호출, Box 래핑 + 깜박임 오버레이
- `PomodoroScreen.kt` — 단계 자동 전환 시 AlertHelper.triggerAlerts 호출, 깜박임 오버레이
- `HomeScreen.kt` — 턴 종료 시 AlertHelper.triggerAlerts 호출, 경고 틱은 getSoundEnabled 확인 후 재생
- `TwoPlayerTimerScreen.kt` — 시간 소진(winner 결정) 시 AlertHelper.triggerAlerts 호출, 경고 틱은 getSoundEnabled 확인
- `strings.xml` × 6 로케일 — alert_label/alert_sound_label/alert_vibration_label/alert_flash_label 추가

## 결정

### 알림 범위 구분
- `MetronomePlayer.tick(warning=true)` → 타이머 종료/단계 완료 시점: 3가지 알림 모두 적용
- `MetronomePlayer.tick(warning=false)` → 10초 간격 주기적 틱: 항상 재생 (설정 무관)
- 경고 틱 (last 10초): 소리 설정 확인 후 재생, 진동/깜박임은 미적용 (1초마다 진동하면 불쾌)

### 깜박임 구현
- 각 타이머 화면 내부에 `Box` 오버레이로 구현 (앱 전체 수준이 아닌 화면별 로컬)
- 12dp 빨간 테두리(`colorScheme.error`), 200ms ON + 200ms OFF × 3회

### 아키텍처
- `AlertHelper.triggerAlerts(context, warning, onFlash)` 패턴
- `onFlash` 람다는 깜박임 활성화 시만 호출되며, 각 화면이 coroutineScope.launch로 애니메이션 실행
