# 타이머-선택-메뉴-화면-추가
날짜: 2026-06-08

## 요청
보드게임 타이머 4종 및 일반 타이머 3종을 선택할 수 있는 메뉴 화면을 추가해달라. 설정 진입도 이 화면에서 가능하게 한다.

## 행동
- `MenuScreen.kt` 신규 생성 — 보드게임 타이머 4종 + 일반 타이머 3종 선택 카드 + 설정 버튼 레이아웃
- `MainActivity.kt` — `Screen` enum에 `MENU` 추가, 기존 햄버거 버튼 → `MENU` 화면으로 라우팅 변경
- `values/strings.xml` — v3 메뉴 문자열 11개 추가 (한국어)
- `values-en/strings.xml` — 메뉴 문자열 11개 영어 번역 추가
- `values-ja/strings.xml` — 메뉴 문자열 11개 일본어 번역 추가
- `values-de/strings.xml` — 메뉴 문자열 11개 독일어 번역 추가
- `values-es/strings.xml` — 메뉴 문자열 11개 스페인어 번역 추가
- `values-nl/strings.xml` — 메뉴 문자열 11개 네덜란드어 번역 추가

## 결정
- 6개 언어 문자열을 한 세션에서 동시 추가 (CLAUDE.md 로케일 동기화 지침 준수)
- 기존 설정 진입 경로(햄버거 버튼)를 MENU 화면으로 통합
